# PaperLens · PDF 论文翻译与解读

一个 Chrome 扩展（Manifest V3）：在浏览器里打开 PDF 论文，**保持原排版做全文翻译**，并自动拆解论文的**创新点 / 技术核心方案 / 实验指标 / 优缺点 / 改进方案**，还能针对这篇论文提问。

全部计算发生在本地浏览器 + 你自己配置的模型服务之间，扩展不会把内容发给任何第三方服务器。

---

## 功能

### 1. 保持排版的全文翻译

不是把 PDF 转成纯文本再翻译，而是先做**版面还原**，再把译文按原文的矩形回填：

- **分栏检测**：用文字覆盖度的「局部山谷」找栏间白槽，双栏、三栏论文都能正确切栏；页面里有通栏标题、通栏表格或大图时也不会误判。
- **成行 / 成段**：按基线聚行，再依据行距、字号、水平重叠、右边界是否排满、首行缩进、悬挂缩进（参考文献样式）等特征合并成段落。
- **阅读顺序**：通栏块作为分隔，把页面切成若干带，带内按「栏 → 从上到下」排序，翻译与全文抽取都按真实阅读顺序。
- **原位回填**：译文覆盖在原段落的矩形上，底色从画布采样（白底、灰底、深色底都能贴合），字号二分搜索自动适配，多行两端对齐，段落下方的空白可少量借用，因此**整页版式、图表、公式位置完全不变**。
- 自动跳过公式、页眉页脚、页码、纯数字表格单元；参考文献默认不翻译（可开）。
- 正文是衬线体的段落，译文自动用宋体；无衬线的用黑体。

翻译按段落缓存（IndexedDB），同一篇论文重开不会重复付费；译文也会持久化，下次打开直接恢复。

### 2. 论文解读

一键生成结构化解读，固定 9 个小节：

一句话总结 · 研究问题与动机 · **创新点**（逐条标注新颖度） · **技术核心方案**（数据流、关键模块、关键公式逐符号解释、训练细节） · **实验与关键指标**（数据集/指标/本文/最强基线/提升 的表格 + 消融结论） · **优点** · **缺点与局限**（审稿式意见） · **可能的改进方案**（思路/预期收益/实现难度） · 复现要点

长论文自动走「分段提要点 → 汇总」，不会因为超上下文而截断。结果可复制或导出 Markdown，并按缓存保存。

输出按 Markdown 渲染（标题、列表、表格、代码块），**LaTeX 公式用 KaTeX 排版**：`$$...$$` 与 `\[...\]` 渲染为独立公式块（过长可横向滚动），`$...$` 与 `\(...\)` 渲染为行内公式。代码块里的 `$` 和正文里的 `$100` 不会被误判成公式。KaTeX 按需加载，不出现公式时不会拖慢启动。

### 3. 针对论文提问

- 侧栏对话，流式输出，携带全文上下文；论文超长时按与问题的相关度挑选段落。
- 选中 PDF 里的任意文字 → 浮出「翻译 / 解释 / 提问 / 复制」，「解释」会给出直译、通俗解释、关键概念与它在全文中的作用。

### 4. 阅读器本身

pdf.js 渲染 + 可选中的文本层（支持 Ctrl+F）、缩略进度、自动大纲（从标题层级还原 1 / 1.1 / 1.1.1）、页面懒渲染与释放、缩放（适合宽度 / 适合页面 / 定值 / Ctrl+滚轮）。

## 安装

1. 打开 `chrome://extensions/`
2. 右上角开启 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录（含 `manifest.json` 的那一层）
4. 首次安装会自动打开设置页

> 需要 Chrome 116 及以上。

## 配置模型

设置页（扩展图标 → 设置，或 `chrome://extensions` → 详情 → 扩展程序选项）：

| 项 | 说明 |
|---|---|
| 服务商 | OpenAI / DeepSeek / Moonshot / 智谱 / 通义千问 / SiliconFlow / OpenRouter / Ollama / 任意 OpenAI 兼容网关 / Anthropic / Gemini |
| Base URL | OpenAI 兼容服务填到 `/v1` 为止 |
| API Key | 只存在本机 `chrome.storage.local` |
| 翻译模型 | 翻译量大，建议用便宜快的模型 |
| 解读/问答模型 | 留空则与翻译模型相同；解读更吃推理能力，可换更强的 |

填完点 **测试连接** 确认可用，再 **保存设置**。

其他可调项：目标语言、并发数（被限流就调小）、每批字符数、译文字体、术语表（每行 `英文=中文`）、附加翻译要求、是否翻译参考文献、是否自动接管 PDF 链接、上下文上限。

## 使用

- 在浏览器里打开任意 PDF 链接（含 arXiv 的无后缀链接、OpenReview），扩展会自动接管并用阅读器打开；也可以右键链接 → 「用 PaperLens 打开此 PDF 链接」。
- 本地文件：点扩展图标 → 「打开本地 PDF」，或把 PDF 拖进阅读器窗口。
- 点 **翻译全文** 开始翻译，进度显示在按钮和顶部进度条上，可随时停止；已翻译的段落即时出现。
- 点 **解读** 打开侧栏 → 生成解读 / 提问 / 大纲。

### 快捷键

| 键 | 作用 |
|---|---|
| `T` | 翻译全文 / 停止 |
| `S` | 开关解读面板 |
| `O` | 打开本地 PDF |
| `←` `→` | 翻页 |
| `+` `-` / `Ctrl+滚轮` | 缩放 |
| **按住 `Alt`** | 临时隐藏译文查看原文 |
| 顶栏「原文」 | 长期切换原文 / 译文 |

## 已知限制

- **扫描版 PDF 没有文本层**，无法翻译或解读，需要先做 OCR。
- 行内公式若被 PDF 拆成大量独立字符，可能被判为「非正文」而跳过；整块公式一律不翻译（这是有意为之，避免破坏公式）。
- 译文比原文长很多时（极少数情况），会先缩小字号，仍放不下才轻微裁切，鼠标悬停可看完整译文。
- 双栏论文里跨栏的作者行、邮箱行可能被切成两块，属于抽取噪声，不影响正文。

## 隐私

API Key 与设置保存在本机 `chrome.storage.local`；译文缓存、解读结果保存在本机 IndexedDB。论文内容只发送到你自己配置的模型服务地址。扩展没有任何遥测。

## 目录结构

```
manifest.json
src/
  background.js        PDF 链接接管（declarativeNetRequest 动态规则）、右键菜单
  lib/
    layout.js          版面还原：分栏 → 成行 → 成段 → 阅读顺序 → 是否需要翻译
    translate.js       批量打包、并发、缓存、校验、失败降级为逐段重试
    llm.js             OpenAI 兼容 / Anthropic / Gemini 三种协议，流式与非流式
    prompts.js         翻译、解读、问答的提示词
    store.js           设置读写 + IndexedDB 缓存
    md.js              轻量 Markdown 渲染
  viewer/
    viewer.html/css/js 阅读器主程序：渲染、缩放、导航、翻译调度、选中操作
    overlay.js         译文覆盖层：背景采样、字号自适配、原位回填
    sidebar.js         解读 / 提问 / 大纲
    math.js            按需加载 KaTeX，排版解读与问答里的 LaTeX 公式
  pages/               设置页、弹出面板
vendor/pdfjs/          pdf.js 4.10.38（Apache-2.0）
vendor/katex/          KaTeX 0.18.7（MIT，仅保留 woff2 字体）
```

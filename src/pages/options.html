PaperLens 设置

一个把 PDF 论文「翻译 + 拆解」的 Chrome 插件。所有 API Key 只保存在本机浏览器，不会上传到任何第三方服务器。

欢迎使用！ 三步开始：① 选择模型服务并填入 API Key；② 保存；③ 打开任意 PDF 论文，点右上角「翻译全文」或「解读」。

模型服务

除 Anthropic / Gemini 外均按 OpenAI 兼容协议调用，可填任意兼容网关。
OpenAI 兼容服务请填到 /v1 为止。
翻译量大，建议用便宜快速的模型。
解读更吃推理能力，可换成更强的模型。

翻译

被限流（429）时调小，一般 3–6。
越大越省钱，但太大容易丢段，推荐 1800–3000。

解读与问答

超过此长度时自动改为「分段提要点 → 汇总」，并在问答时按相关度挑选段落。
